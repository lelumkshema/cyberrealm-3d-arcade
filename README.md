**CyberRealm** is an ultra-advanced, high-performance sci-fi web gaming platform built with **Three.js (3D WebGL)**, **HTML5 Canvas**, **Web Audio API**, and **Speech Synthesis Voice AI**.

---

## 🌟 Featured Games & Modules

### 1. 🏎️ CYBER I.G.I. 3D ADVANCED WARFARE
- **Full 3D WebGL Engine**: Three.js rendered 3D armored combat vehicle with rotating wheels, dual gatling cannons, and 3rd person chase camera.
- **3D Enemy Base**: 3D spinning military radar dishes, 3D enemy patrol tanks, 3D watchtowers with red searchlight cones, atmospheric fog, and dynamic shadows.
- **Homing Missiles (`F` Key)**: Lock-on tracking system with curved 3D homing missiles and smoke particle trails.
- **EMP Shockwave (`E` Key)**: Expanding 3D plasma ring stunning nearby enemy electronics.
- **Tactical HQ Voice AI**: Real-time voice announcements (*"Radar destroyed!"*, *"Intel acquired"*).

### 2. 🏎️ 3D ARMORY GARAGE
- **360° Mouse Orbit Inspector**: Inspect your 3D combat car in real-time.
- **Customizations**: Body paints (Cyber Cyan, Magenta Viper, Gold Cyberlord, Stealth Black, Neon Emerald), Neon Underglow lighting, and Turret loadouts.

### 3. 🚀 CYBER STRIKE
- 2D Sci-Fi Space Shooter featuring enemy droids, dreadnought bosses, shields, and laser upgrades.

### 4. ⚡ NEON PULSE
- 4-lane synthwave rhythm arcade game with key tapping, combo multipliers, and fireworks.

### 5. 🔑 CYBER MAZE RUNNER
- Hacker mainframe grid puzzle game to collect data nodes while dodging red ICE security bots.

## 🛠️ Tech Stack

- **Graphics Engine**: Three.js (WebGL), HTML5 Canvas 2D
- **Framework**: React 18, Vite
- **Styling**: Cyberpunk CSS Design System, Glassmorphism, Neon Glow Effects, Google Fonts (Orbitron, Press Start 2P, Outfit)
- **Audio & Speech**: Web Audio API Synthesizer, Web Speech Synthesis API
- **State & Storage**: React Hooks, LocalStorage Persistence

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/lelumkshema/medvision-ai.git

# Install dependencies
npm install

# Start development server
npm run dev -- --port 3000

# Build production bundle
npm run build
```

Open `http://localhost:3000` in your web browser!
